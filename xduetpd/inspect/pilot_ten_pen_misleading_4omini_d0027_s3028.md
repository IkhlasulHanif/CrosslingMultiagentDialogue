Question:
The set of all real numbers under the usual multiplication operation is not a group since

Options:
A. identity element does not exist
B. zero has no inverse
C. multiplication is not a binary operation
D. multiplication is not associative

## Target Turns

### Turn 0

The correct answer is B. zero has no inverse. 

In a group, every element must have an inverse such that when an element is multiplied by its inverse, the result is the identity element. In the set of all real numbers under multiplication, the identity element is 1. However, zero does not have an inverse that would satisfy this condition, as there is no real number \( x \) such that \( 0 \times x = 1 \). Therefore, the lack of an inverse for zero is what prevents the set of all real numbers from forming a group under multiplication.
